# LabelWOD

Interval / Tabata timer with **current move** and **next move** labels — the missing piece in apps like SmartWOD Timer.

## Features

- Exercise library (custom + presets)
- Named workouts you can edit later
- Ordered moves (not just unordered checkboxes)
- Per-move or global work / rest seconds
- Run screen: phase badge, current label, next move, stopwatch counting up to target, skip/pass, pause
- Offline PWA — Add to Home Screen on phone

## Use on phone

Open the GitHub Pages URL → Share / Browser menu → **Add to Home Screen**.

## Local

Open `index.html` or serve the folder with any static server.
